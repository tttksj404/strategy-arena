## 2. 벡터화 평가기 — 1,826배 가속, 기계 정밀도 일치

기존 wave들은 조합을 하나씩 평가했다(engine38 ≈ 36ms/조합). 그래서 격자가 54~9,720에 묶였다.

**구조적 사실**: 임계값을 고정하면 캐리 장부의 일별 수익은
```
r_t = leg_eff × (선택된 top-k 종목의 basis+funding 합) − 회전비용,  leg_eff = min(leg, cap/k)
```
로 분해된다. 비싼 부분(히스테리시스 상태기계, 일별 랭킹)은 **임계값과 k에만** 의존하고 `leg`·`cap`과는 무관하다. 따라서 (임계, k)마다 한 번 계산해두면 수백만 (leg, cap) 조합은 순수 산술이다.

**검증 (필수)**:

| 조합 | engine38 | fast53 | 상대오차 |
|---|---|---|---|
| k1 leg0.50 cap0.50 | $141.32 | $141.32 | **5.17e-14** |
| k2 leg0.50 cap1.00 | $223.66 | $223.66 | 1.27e-16 |
| k3 leg0.25 cap0.75 | $173.73 | $173.73 | 6.87e-15 |

첫 구현은 상대오차 **2.64e-02**로 실패했다. 원인: engine38은 **전일 보유로 갭 손익 → 회전비용 → 장중 베이시스 → 펀딩** 순서로 각각 복리 적용하는데 나는 넷을 합산해 한 번에 곱했다. 네 계열을 분리하고 순서를 맞춰 해결했다. **wave50이 보여준 대로, 빠른 오답은 느린 정답보다 나쁘다.**

속도: **50,721조합/초** (engine38 대비 약 **1,826배**)

## 4. 🏆 경험적 귀무분포 — 캐리 edge는 탐색 산물이 아니다

### 왜 이 검정인가

53개 wave에서 취소가 반복됐다(wave44 상장 인공물, wave45 기준선 부풀림, wave50 슬라이서 windfall). 남는 근본 의문은 하나였다: **이 중 뭐라도 실재하는가, 아니면 전부 탐색의 산물인가.**

White's Reality Check가 이것을 수치로 답한다: **무의미한 신호를 동일 강도로 전수 탐색했을 때 우연히 얻어지는 최고 성과의 분포**를 만들고, 실제가 그것을 넘는지 본다.

### 귀무 구성 (핵심)

**신호만 일자별로 종목 간 순열**한다. 전략은 자기 종목과 아무 관계없는 값으로 게이트하고 랭킹한다. 반면 **실현 펀딩·베이시스·가격·비용은 그대로** 둔다 — 포지션이 벌어들이는 것은 그 종목의 실제 현금흐름이어야 한다. 수익 쪽을 순열하면 선택에 대해 아무것도 검정하지 못한다. 신호의 주변분포는 구성상 보존되므로 **귀무 전략도 실제와 같은 빈도·같은 임계로 거래한다.**

### 결과 (복제 50회, 각 복제가 19,200조합 전수 탐색)

| | 값 |
|---|---|
| **실제 신호 최고** | **+14.16%** |
| 귀무 중앙 | +1.08% |
| 귀무 평균 | +1.06% |
| 귀무 표준편차 | 0.28% |
| 귀무 **최대** | **+1.80%** |
| 귀무 p95 | +1.44% |

- **실제가 귀무 최고의 7.9배**
- **귀무 평균 대비 46.6σ**
- **실제 ≥ 귀무인 복제 0/50 → p = 0.020**

**p = 0.020은 복제 수가 만든 하한**(1/51 = 0.0196)이다. 데이터가 아니라 복제 예산이 p를 제약한다 — 46.6σ는 실제 p가 천문학적으로 작음을 뜻한다.

흥미로운 세부: 귀무 최고는 **50복제 전부에서 k5·임계35%**를 골랐다. 잡음을 최대한 긁어모으는 구성이 일관되게 선택된다.

### 이것이 확립하는 것과 하지 않는 것

**확립한다:**
- **펀딩 신호는 실재하는 횡단면 정보를 담는다.** 펀딩으로 종목을 고르는 것이 무작위로 고르는 것을 압도한다.
- **전기간 +14.16%(및 wave42의 +13.31%)는 데이터 스누핑으로 설명되지 않는다.**
- 53개 wave의 다중검정을 감안해도 남는 신호다.

**확립하지 않는다:**
- **최근 레짐 크기**: 이 검정은 전기간이고 그 기간은 2021년이 지배한다. 2023년 이후 +2.41%가 유의한지는 별개 문제다.
- **훈련창 선정의 전이**: wave34·37·38·43·50·51·52가 전부 전이 실패를 보였고 이 검정은 그것을 뒤집지 않는다.
- **$100에서의 실용성**: 연 +2.41%는 $100에서 약 $2다.

## 7. 후속 — 최근 레짐(2023년 이후)에도 같은 검정을 적용했다

§4는 전기간 검정이고 그 구간은 2021년이 지배한다. **실제로 배포할 구간은 최근**이므로 거기서도 신호가 살아있는지가 배포 여부를 정한다. 동일 프로토콜을 **2023-01-01 ~ 2026-07-14 (1,291일, 3.54년)** 에만 적용했다.

**구현 주의**: 일별 계열은 항상 **전체 패널**에서 만들고 평가만 하위구간으로 제한한다. 계열을 하위구간 시작부터 다시 만들면 첫날에 빈 장부로 시작하게 되는데, 그것은 **실거래에서 이어받는 히스테리시스 상태를 지운 더 쉬운 문제**다.

### 결과

| | 전기간 (6.87년) | **2023년 이후 (3.54년)** |
|---|---|---|
| 실제 신호 (축소격자) | **+14.16%** | **+3.71%** |
| 실제 신호 (전체격자 56,000조합) | +14.16% | **+4.40%** |
| 귀무 중앙 | +1.08% | **−0.40%** |
| 귀무 **최대** | +1.80% | **−0.31%** |
| 귀무 표준편차 | 0.28% | 0.08% |
| **σ 거리** | **46.6σ** | **49.3σ** |
| 실제 ≥ 귀무 | 0/50 | **0/50** |
| **p** | **0.020** | **0.020** |
| 최적 구성 | 임계15% k2 · MDD 4.57% | 임계15% **k12** · MDD **0.77%** |

### 🔑 최근 레짐 결과가 전기간보다 더 강한 증거다

**2023년 이후 귀무 최고가 −0.31%로 음수다.** 50복제 전부에서 음수였다. 즉 **무작위로 종목을 고르면 회전비용 때문에 반드시 손실**이다.

그 구간에서 실제 신호가 **+3.71%** 를 내는 것은 **비용을 넘는 정보가 있다는 직접적이고 부인하기 어려운 증거**다. 전기간 검정에서는 귀무도 +1.08%를 냈으므로(시장 전반의 베이시스 순풍) 실제와 귀무의 차이가 "정보"와 "순풍"으로 혼재할 수 있었다. **최근 레짐에서는 순풍이 없고 비용만 있으므로 차이가 순수하게 정보다.**

**따라서 캐리 edge는 2021년 의존이 아니다.** 두 구간 모두 p=0.020, 46.6σ와 49.3σ.

### 최적 구성이 구간별로 다르다

- 전기간: k**2**, MDD 4.57%
- 2023년 이후: k**12**, MDD **0.77%**

최근 레짐에서는 **더 넓게 분산하고 훨씬 작게 잡는 것**이 최적이다(leg 0.099). 펀딩 수준이 낮아져 집중의 이득이 줄고 비용·변동성 관리가 상대적으로 중요해진 것과 일치한다. wave38이 "폭은 위험 레버"라고 측정한 것의 레짐 의존적 확인이다.

### 이것이 바꾸는 것

**배포 판단의 근거가 달라진다.** 이전까지 "2023년 이후 +2.41%"는 **크기는 작지만 실재하는지 불명**이었다. 이제 **실재한다**(49.3σ, 귀무 최고가 음수인 구간에서 양수).

여전히 바뀌지 않는 것: **크기다.** 사후 최적이 +4.40%, 인과 워크포워드가 +2.41%. $100에서 연 $2~4다.

*(운영 메모: `--from-year` 실행은 `results/final_{period}.json`에 저장되어 전기간 판정을 덮어쓰지 않는다. judge 단계의 마지막 출력 문구가 항상 `results/final.json`으로 표시되는 것은 표시 오류이며 저장 경로는 올바르다.)*
