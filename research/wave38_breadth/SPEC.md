# Wave-38 SPEC — 검증된 캐리의 폭(breadth) 확장

**동결 2026-07-30. 실행 전 사전등록. 이 문서는 결과를 본 뒤 수정하지 않는다.**

## 왜 이 wave인가

캠페인에서 **게이트를 통과한 계열은 단 하나** — 델타중립 캐리(L4/I5, 전기간 CAGR 10.27%)다. 방향성 예측(wave19·21~24·30~34), 20x 레버리지(wave30), 횡단면 펀딩(wave36 무효 / wave37 −22.32%)은 전부 닫혔다.

그런데 **검증된 그 계열 자체가 자본을 거의 쓰지 않는다**:

- `top_k=1` — 하루에 단 1종목만 보유
- `leg_fraction=0.50` — 활성일에도 자본의 50%만 투입
- 활성일 59% / **대기 41%**

wave18은 이 대기 41%를 "최대 미개발 자원"으로 지목하고 USDT 대여로 채워 +0.90%p를 얻었다(9.37%→10.27%). 하지만 **활성일의 미사용 50%와 `top_k=1`이 버리는 자격 기회**는 손대지 않았다.

`probe_opportunity.py` 실측(사전 측정 완료, 백테스트 아님):

| | 실측 |
|---|---|
| 15% APR 기준 통과 종목이 2개 이상인 날 | **42.9%** |
| 5개 이상인 날 | 29.9% |
| `top_k=3`이 버리는 2~3위 펀딩 APR | 1위 대비 **+137%** |
| `top_k=5`가 버리는 2~5위 | 1위 대비 **+251%** |

## 가설

**H1**: 품질 기준(15% APR)을 **그대로 유지**한 채 `top_k`를 늘리면, 자격을 갖춘 채 방치된 캐리를 회수해 I5의 10.27%를 넘는다.

**I3와 무엇이 다른가 (반드시 구분)**: I3는 기준을 **8%로 낮춰** 저품질 캐리를 담았고 CAGR 8.72%로 기준선 미달이었다 — 회전비용이 저펀딩 수익을 초과했다. H1은 기준을 낮추지 않는다. **이미 15%를 넘은 종목만** 담는다. 하나는 신호를 훼손하고, 하나는 같은 신호를 더 수확한다.

**H2**: 동일 자본에서 `top_k`만 쪼개면(총투입 고정) 펀딩은 **줄어든다** — 낮은 APR 종목을 평균에 섞기 때문. 따라서 이득은 **총투입 확대**에서만 나온다. 총투입 1.0(무레버리지 전액)까지는 레버리지 없이 도달 가능하고, 그 이상은 레버리지다. 이 경계를 명시적으로 분리해 측정한다.

## 데이터

- **출처**: `research/wave3/cache` 단일 (`binance_spot_*_1d`, `binance_fapi_*_1d`, `binance_funding_*`) — 신호·펀딩·현물·선물 전부 동일 거래소(Binance). wave36을 무효화한 데이터원 불일치를 원인적으로 배제.
- **종목**: 3레그(현물+선물+펀딩) 모두 존재 + 이력 충분 = **330종목**
- **왜 `wave13/wave18`의 캐시를 쓰지 않는가**: `wave12_frontier/cache`에 `binance_fapi_AAVEUSDT_1d.csv.gz` 등이 없고 폴백 체인(wave11→wave1)에도 없어 **L4/I5는 현재 재현 불가**다. 그 캐시를 채우면 L4 유니버스가 바뀌어 I5의 검증 결과가 재현 불가능해진다. 검증된 산출물을 훼손하지 않기 위해 wave37과 동일하게 `wave3/cache`에 독립 구축한다. (이 캐시 결손 자체를 리포트에 기록한다.)
- **비용**: `research.wave13_liquidity.costs_measured` 실측 매핑 재사용(추측 금지 — wave13 교훈)
- **유동성**: 일평균 거래대금 하한 적용, 미달 종목 당일 제외

## 자본 계약

wave10 계약 승계: **총 $100**, 예비 10%, **활성 $90**. 최소주문 **$5** 강제(wave37이 $0.40 레그를 체결한 결함 정정).

## 전략

각 일자에 대해:
1. 7일 펀딩 APR 계산(`fam_funding.funding_score` 규약: 8h 요율 평균 × 3 × 365)
2. `carry_position` 히스테리시스 적용(진입 > 15%, 청산 < 7.5%) — **L4와 동일, 변경 없음**
3. 자격 종목을 APR 내림차순 정렬, 상위 `top_k` 선택
4. 각 종목에 **현물 롱 + 퍼프 숏**(델타중립), 레그당 `leg_fraction`
5. 총투입 = `min(leg_fraction × k, deployment_cap)`; 초과 시 균등 축소
6. 최소주문 미달 레그는 제외

수익 = Σ wᵢ × (현물수익 − 퍼프수익 + 펀딩) − 회전비용. 델타중립이므로 가격항은 베이시스만 남는다.

## 탐색 — 인과적 워크포워드 (전수 그리드)

wave37이 확립한 규율을 그대로 따른다. **홀드아웃을 다시 열지 않는다**(이미 6회 사용).

- `top_k` ∈ {1, 2, 3, 5, 8}
- `leg_fraction` ∈ {0.25, 0.50}
- `deployment_cap` ∈ {0.50, 1.00, 2.00, 3.00} — 0.50=현행 L4, 1.00=무레버리지 전액, 2.00·3.00=레버리지
- 훈련 365일로 전수 평가 → 1개 선정 → 다음 90일 적용 → 반복
- 적용창은 선정에 사용 금지 → **연결 곡선의 모든 점이 생성 시점에 OOS**
- 선정 점수 = 수익 − 2×(MDD−20%)⁺ (wave37과 동일한 낙폭 벌점)
