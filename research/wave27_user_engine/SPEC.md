# Wave-27 사전등록 — 사용자 기존 엔진의 조합 공간 GA 탐색 (동결: 2026-07-29)

## 왜 이 wave가 필요한가 (내 누락 인정)
wave-1~26 내내 나는 **내가 정의한 신호만** 시험했고, 리포 루트의 `engine.py`(1,381줄, 사용자가 이 캠페인 이전에 구축)를 **한 번도 열지 않았다**. wave-25에서 "미탐색"이라며 MACD·ADX·스토캐스틱을 새로 구현했으나 **이미 거기 있었다**. 더 중요한 건 접근 방식의 차이다:
- **내 방식**: 지표 하나씩 단독 시험(MACD 단독, ADX 단독…) → 전부 실패
- **사용자 엔진**: **신호 + 필터 + 청산을 조합**(`generate_signals`: 필터 AND 마스크 → 신호 우선순위 적용 → 사이징)
**조합 공간은 한 번도 탐색되지 않았다.** 그리고 CCI·OBV 다이버전스는 내가 아예 안 건드린 신호다.

## 탐색 공간 (사용자 엔진의 컴포넌트, 재구현 금지 — `engine.py` 함수 그대로 호출)
| 범주 | 컴포넌트 |
|---|---|
| 신호(1~2개 선택) | ema_cross, macd_cross, boll_bounce, boll_breakout, price_breakout, volume_breakout, stoch_rsi_cross, **cci_signal**, **obv_divergence** |
| 필터(0~3개) | adx_filter, trend_filter, volatility_filter, volume_filter, rsi_range_filter, time_filter |
| 청산(1개 필수) | atr_stop, trailing_stop, breakeven_stop, fixed_stop |
| 사이징 | fixed_risk, drawdown_breaker, direction(long/short/both) |
| 파라미터 | 각 컴포넌트의 기간·배수·임계 (엔진 기본값 ±범위) |
조합 규모 ≈ 9C2 × 6C3 × 4 × 파라미터 ≈ **10^5 이상** → GA 적합.

## GA 설정 (wave-21/23 검증된 골격 재사용)
개체 150 × 세대 25 × **5시드**(2027101~2027105) + **동일 예산 랜덤 대조군**. 토너먼트 k=3, 균등교차, 변이 p=0.15, 엘리트 2.

## 적합도 — 도박 티어(사용자 요구: 단기 최고수익)
`fitness = 30일 롤링창 상위25% 평균수익 − 5×P(창손실 > 25%) − 0.01×컴포넌트수`
- 단기 대박 능력을 목표로 하되 **파멸은 강하게 벌점**. 복잡도 페널티로 과최적화 억제.

## 오염 차단 (전 wave 계승, 타협 불가)
1. **OOS 봉인**: 진화는 IS(~2025-09)만. OOS 1회. 코드 가드 + 테스트 강제.
2. **랜덤 대조군**: GA ≤ 랜덤이면 "GA 무의미" 판정.
3. **DSR을 최종 개체 자신의 곡선으로** 계산(wave-21 실수 재발 금지). 누적시행 = 137후보 + 82,621 + 이번 평가수.
4. **5시드 재현성**: 4/5 이상에서 유사 구조(동일 신호군) 출현해야 인정.

## 게이트
- **R1** GA > 랜덤 (5시드 중 4+)
- **R2** OOS 성과 > V1(도박 기준선: 슬리브 $25→$138.48)
- **R3** DSR(자체 곡선, 누적보정) > 0
- **R4 파산(타협불가)**: MC 1e4 P(전체<$50) < 10% ∧ 단일 최대손실 ≤ $25
- **R5** 볼록성: 왜도 > 0 ∧ 상위10% 거래가 총이익 50%+
- **R6** 실행가능: 실측슬리피지 ×3 스트레스 부호 유지
- **승격 = R4 필수 + R1·R2·R3·R5 중 3개 이상**(도박 티어이므로 R6는 권고)
