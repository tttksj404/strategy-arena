# 도박수 옵션 — V1 (wave-20, 2026-07-28 라이브 확인)

## 왜 이것만 남았나
도박 후보는 여러 번 죽었다: 대칭 방향베팅(wave-9, 6개 중 5개 원금 전소), GA 단기최적해(wave-23, 원금 82% 손실 위험), 역캐리(wave-18 I4, 패닉 때 차입 동결로 실행불가), 역방향 ETF 페어(오늘 2차, -8.33%/일).
**V1만 볼록성·파산 게이트를 모두 통과했다.** 떨어진 건 G5(최악연도 방어) 하나뿐이고, 그건 안전성 실패가 아니라 **감수 여부를 사용자가 정하는 항목**이다.

## 구조
**BTC 퍼프 양방향 돌파 추격** — 저변동 구간에서 대기하다 ±2×ATR(14일) 돌파 시 그 방향 진입, 반대로 돌파하면 반전. 손실은 whipsaw 소액 반복, 이익은 대추세 시 무제한(볼록).
- 자본: **$100 = 도박 $25 + 안정 I5 $75**. 도박 슬리브는 구조적으로 $25 초과 손실 불가.

## 실측 (153거래, 전기간)
| 항목 | 값 |
|---|---|
| 도박 슬리브 | $25 → **$138.48** |
| 전체 시스템 CAGR | **16.47%** (I5 단독 10.27%) |
| MC 5%분위 | **$112.93** (원금 이상) |
| **파산확률** | **0.11%** |
| 왜도 / 부트스트랩 하한 | 1.760 / **1.219** (볼록성 견고) |
| 최대거래 제외 시 | $138.48 → $86.20 (1건 의존도 있음, 전부는 아님) |

## 대가 — 이게 G5 탈락 사유이자 감수할 항목
| 연도 | V1 결합 | I5 단독 | |
|---|---|---|---|
| 2022(폭락장) | **+15.83%** | +1.75% | ✅ 돌파 포착 |
| **2025(횡보장)** | **-13.05%** | 양수 | ❌ **whipsaw 손실** |

**V1은 큰 방향이 나오는 해에 이기고, 횡보하는 해에 진다.** 2025년형 장세가 오면 안전형이 벌 때 13% 잃는다. 이게 유일한 실패 지점이고, 파산 위험이 아니라 **기회비용 + 변동성**이다.

## 오늘의 상태 — 진입조건 켜짐 ✅
```
BTC 현재가       $63,711
ATR(14일)        $1,444
실현변동성 20일   1.43%/일 → 3분위 (진입조건: 30분위 미만) ✅
상단 돌파선      $66,598  (+4.5%)
하단 돌파선      $60,824  (-4.5%)
```
**BTC가 3분위 극단 저변동 = V1이 설계상 노리는 "눌린 스프링" 상태다.** 지금 대기 진입하고, 위로 $66,598 뚫으면 롱, 아래로 $60,824 뚫으면 숏. 반대 돌파 시 반전.

## 실행안
```
대기 상태 진입 (도박 슬리브 $25, BTC 퍼프 1x)
상단 트리거  $66,598 → 롱 $25
하단 트리거  $60,824 → 숏 $25
반대 돌파 시 반전, 손실 한도 $25(구조적)
나머지 $75 → I5 캐리(현재 SOONUSDT 대기)
```
