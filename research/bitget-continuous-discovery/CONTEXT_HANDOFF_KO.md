# 대화 맥락과 연구 인계

## 사용자가 원한 것

처음에는 strategy-arena 최신 내용을 받아 주로 알트코인에서 5배 레버리지로 청산을 피하며 수익을 극대화하는 전략을 찾도록 요청했다. 여러 시간봉과 더 넓은 파라미터뿐 아니라 구조적으로 다른 알고리즘을 탐색해야 한다고 강조했다. 이후 청산 회피를 완화한 단기 최대수익 탐색을 기존 안전성 탐색과 병행하도록 요청했다.

후속 요구는 텔레그램 타점·TP·SL의 일반 원리가 아니라 실제 연구에서 수익률이 높았던 전략의 진입·퇴장 판단을 차트에서 직접 따라 할 수 있는 상세 PDF였다. 방향만 결국 맞으면 고배율로 버틸 수 있다는 가설도 제시했다. 마지막으로 코드·결과·실패 이유·맥락을 Git에 보관하고 푸시하도록 명시했다.

2026-09-10에는 X 링크 3개를 검토·실험하도록 요청했고, 진행 중 기관 옵션 흐름과 Grok 밈코인 운영법 링크 2개를 추가했다. 소셜 글의 외부 프롬프트는 조사 자료로만 읽었으며 결제, 키 발급, 소개 링크 가입, 텔레그램 메시지나 실주문을 실행하지 않았다.

## 이전 연구에서 확보한 결과

기존 139,536개 탐색의 선택편향 검증은 PBO 41.4286%로 기준 5%를 넘었다. Donchian 후보의 DSR 근사 확률은 1.4680%, Price-Volume은 약 0.00907%로 95% 기준에 못 미쳤다. 이 수치는 일반적인 방향 적중률이 아니다.

Donchian-90의 변동성 조정·5배 상한 후보는 역사 test raw +55.4650%, 스트레스 +52.5866%, MDD 9.1505%였다. 실제 실효배율 중앙값은 약 0.2894배로 상시 5배가 아니었다. 완결 포지션 방향 적중률은 약 45.45%로 ‘결국 방향이 항상 맞는다’는 가설을 지지하지 않았다.

Price-Volume-60은 60일 가격 모멘텀과 상대 거래대금으로 1위 롱/최하위 숏, 각 0.5를 두며 2일마다 재조정한다. 어느 한쪽의 2천만 USDT 거래대금 guard가 실패하면 해당 pair 전체가 0이다. 역사 test raw +20.4189%, 스트레스 +15.3315%, MDD 13.3705%였고 paper 기준 일부는 통과했지만 PBO/DSR은 실패했다.

후속 고정 배율 frontier는 40개 검증 조합 중 Donchian 2배를 선택했고 역사 test raw +177.8403%, 스트레스 +161.3212%, 스트레스 MDD 23.1313%였다. 개발구간 스트레스 MDD는 47.9739%였고, 2.25배에서는 개발구간 청산 프록시가 발생했다. 이 frontier 내부 test 조회는 선택 후 1회지만, 원천 전략은 이미 과거 test를 본 탐색에서 나온 것이므로 전체 선택 독립성을 주장하지 않는다.

5분/15분 adaptive 탐색도 보관한다. 각각 48개 조합을 탐색했고 5분 승자의 validation/test 스트레스는 -3.98388%/-4.43447%, 15분 승자는 -3.07282%/-3.84069%였다. 고정 명목 합산 결과와 복리 계좌 수익은 구분한다. 단기 방향전환, OLMAR, 회귀·트리·랜덤특징·VAR, PCA/칼만/동적 페어, 레짐/요인/리스크패리티 등 시행한 가족의 코드·실패 보고서를 함께 보관한다.

## X 추가 실험의 해석

245개 사전등록 그리드는 OU 페어, BTC/ETH 잔차 추세·반전, 전체 종목 분모 Donchian 변형, 거래량 급증 캔들 후행 가설을 비교한다. 비중은 고정 1/2/5 및 quarter-Kelly 2종류다. 1H/4H/1D를 같은 UTC 평가 경계로 정렬했고 사전 고정한 12개 조합만 역사 test에서 조회했다.

일봉 입력을 intraday 저장소에서 찾던 첫 실행은 중단되었다. 기존 daily_v2 저장소와 loader를 연결하고 재실행했다. 실패 로그도 보관한다. 결과가 안 좋다는 이유로 테스트 구간이나 임계값을 바꾸지 않았다.

처음 대조군이라고 부른 새 Donchian의 분모가 기존 active-N과 달랐다는 점은 결과 확인 뒤 확인했다. 기존 결과를 덮어쓰지 않고 `X_CONTROL_PREREG_20260910.md`에 원본 코드 재사용과 1H/5분 거래량 ablation 9개를 추가 등록했다. 이 실험은 v2 뒤에 설계한 보조 대조이며 새로운 독립 test가 아니다.

추가 회귀에서는 완전한 24시간 거래량 0을 건강한 비율 1로 취급하던 경계를 재현하고 0으로 수정했다. 미완료봉을 제외하는 시점 계약은 유지한다. 모든 실행 수익은 수정 이력과 별개로 원본 보고서에 남긴다.

## PDF와 남은 업무 경계

16쪽 상위 전략 PDF는 실제 신호 코드·보고서·차트 사례와 대조했다. Price-Volume 배율에 `00.6009x`/`max max`가 중복되던 문자열 치환을 회귀 테스트로 고쳤다. “상위 전략 설명” PDF와 초기 일반적인 차트 안내서는 같은 산출물이 아니므로 최종 안내 링크는 전자를 가리킨다.

청산 뒤 반등을 수익에 다시 합산하는 계산은 배제한다. 고배율에서 버티려면 방향뿐 아니라 중간 역행·증거금·실효 노출·거래비용을 통과해야 한다. 현재 어떤 결과도 원금 보장이나 실전 자동 승격 근거로 쓰지 않는다. 원시 mark/MMR/펀딩·상장/상폐 point-in-time 우주·실제 체결 자료와 독립적인 미래 평가가 남아 있다.

이번 출판은 연구 기록의 보관이지 운영 전략 설정 변경이 아니다. 원래 저장소의 README/app.py/다른 테스트/Docker 변경은 별도 사용자 작업으로 보존한다.

사용자가 로컬 API 키 파일을 제공하며 시세 수집에만 사용하도록 허용했다. 값은 화면·로그·소스에 출력하지 않았고, 공개 시세 API가 무인증을 지원하므로 네트워크로 키를 전송하지 않았다. private/order/account 경로는 호출하지 않았다. 새 스냅샷의 196개 그룹·645,134봉은 시간 순서·양끝 범위·내부 누락·중복·OHLC·파일 해시 검증을 통과했다. ‘과거 전체 데이터’는 기존 확보 범위와 API/상장 이력의 한계를 함께 표시하며, 새 갱신분만으로 전역사 수집 완료를 주장하지 않는다.
