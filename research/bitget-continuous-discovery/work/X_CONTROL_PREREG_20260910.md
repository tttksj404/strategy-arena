# 원본 Donchian 및 5분 거래량 청산 대조 사전등록

245개 v2 결과를 확인한 뒤 작성한 보조 실험이다. v2를 덮어쓰지 않으며, 전체 탐색의 새로운 독립 OOS라고 주장하지 않는다.

v2 Donchian은 신호를 전체 알트 수 13으로 나누었다. 기존 `alt_search_signals._donchian_positions`는 그날 **돌파한 활성 종목 수 N**으로 나눈 뒤 개별 유동성 guard를 적용한다. 따라서 v2의 일봉 2배 결과를 기존 +161.32% 전략의 동일 대조군이라고 부른 것은 부정확하다. 고정 크기 변형 결과로 남기고 아래 통제 비교를 시행한다.

수정 범위는 원본 `build_positions`를 직접 호출하는 어댑터다. 후보는 Donchian lookback90, direction1, rebalance1, minimum_daily_quote_volume=1e6. BTC를 제외한 기존 13개 알트의 활성 신호 동일가중을 그대로 만든다. 임의로 테스트 성과가 좋은 종목이나 비중을 고르지 않는다.

1. 원본 일봉 신호의 1/2/5배: 기존 문서의 2배와 고배율 위험을 같은 다음 시가 계좌 계산으로 비교한다.
2. 원본 일봉 신호를 각 시점에 이미 결정되어 있는 가장 최근 일봉 포지션으로 1시간 및 5분 가격에 투영한다. 고정 2배, 거래량 종료 임계값 off/0.20/0.50의 3개씩, 합계 6개 비교. 원문 규칙은 0.20이며 0.50은 민감도 분석이다. 총 9개 시나리오, 각각 validation/test를 한 번 평가한다. 시나리오 재선택은 없다.
3. 5분 봉은 6h=72봉, 24h=288봉 합으로 계산하고 1H는 6/24봉으로 계산한다. 현재 미완료봉 거래량은 제외한다. 신호가 계속 유효한 상태에서 거래량 조건이 회복되면 재진입한다. 이는 동일 진입 신호에 위험 필터를 붙인 ablation이며 원문 전체 밈코인/예측시장 전략의 재현이 아니다.

v2 계좌 엔진과 시간 경계를 그대로 쓴다. 각 봉에 계좌자산 기준 목표 명목 비중으로 재조정하므로 일봉/1H/5분 사이에는 재조정·체결 경로 차이도 있다. 거래량 필터의 인과 비교는 반드시 **동일 관측 주기 내부** off 대 on을 사용한다. 단순 시간봉간 차이를 거래량 필터 효과라고 해석하지 않는다.

시장봉 고저가/다음 시가 갭을 쓰는 계좌 전체 청산 프록시다. 실제 Bitget mark/MMR/격리 증거가 아니다. 스트레스 편도 비용 0.18%와 보유비용 3bp/일, 거래소 최소 주문·호가 충격·실제 펀딩 누락은 그대로다. 원문의 60초 체결 SLA도 검증하지 않는다.

특히 기존 보고서의 close-to-close와 0.12% 스트레스 편도 비용, 새 next-open과 0.18% 스트레스/보유비용은 서로 다르다. 이전 성과와 새 수치를 교체하지 말고 계약 차이를 명시해서 나란히 보관한다.
