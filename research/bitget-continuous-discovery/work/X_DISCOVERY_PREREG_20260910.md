## 자료와 시간 분리

기존 해시 검증 Bitget 시장가격 아카이브를 사용한다. 1H, 4H, 1D를 동일한 UTC 시간 경계로 비교한다. 자료의 마지막 관측은 2026-08-24 스냅샷이며 새 게시물보다 오래되었다. 이미 다른 탐색에 사용된 기간이므로 이번 test는 새로운 미관측 OOS가 아닌 **재사용 역사 평가 구간**이다.

원천 저장소는 intraday `bitget_history_full_intraday_20260824_v5`, daily `bitget_history_full_daily_20260824_v2`로 분리되어 있다. 최초 실행이 1D를 intraday에서 읽다가 중단되어 이 연결만 수정했다. 실패 실행에는 test 조회·수익 기반 규칙 변경이 없었다.

- 학습 종료: 2024-04-22 16:00 UTC. 페어 풀 선정은 이 시각 이전 자료만 사용.
- 신호/비중 워밍업: 학습 종료부터 60일. 해당 기간은 선택 점수에 포함하지 않음.
- 검증 거래 시작: 2024-06-21 16:00 UTC.

- 모든 거래 평가 종료: 2026-08-22 16:00 UTC. 마지막 가격은 종결 체결용.

고정된 생존 종목 14개(BTC 포함)를 사용하는 생존편향 한계가 남는다. 사용하지 않는 오래된 학습 자료를 실제 거래 평가 기간으로 계산하지 않는다.

## 후보 195개

각 시간봉에서 신호 13개 × 비중 정책 5개 = 65개, 총 195개.

1. OU 페어: 학습 마지막 60/120일의 78개 알트 쌍을 Engle–Granger 검정(p≤0.05, 고정 lag=1) 후 p값 순 상위 최대 6개로 고정한다. β는 0.2~5.0, OU AR(1) 계수는 0<φ<1, 반감기는 2봉~추정창/4이어야 한다. 매일 과거 창으로 β·OU를 재추정하고 7일마다 공적분을 다시 검사한다. s-score 진입 1.5/2.0, 평균 통과·통계 조건 실패·최대 min(4×반감기,10일) 후 종료. 다중 페어를 등비중, 두 다리는 β로 헤지한다. 개별 거래의 OU 평균을 보장하지 않는다.
2. BTC/ETH 요인 잔차: 과거 30/60일 회귀로 알트 수익의 BTC/ETH β를 제거한다. 최근 3/7일 잔차 누적값을 잔차 변동성으로 나눠 상·하위 2개를 추세/반전 방향으로 매일 매매한다. BTC/ETH를 이용해 추정 β를 상쇄하고 총 명목 노출을 정규화한다. 이는 Fama–French 주식 5요인 모델이 아닌 별도 코인용 가설이다.
3. Donchian 대조군: 직전 완료봉 종가가 그 봉을 제외한 이전 90일 최고/최저를 돌파하면 롱/숏, 아니면 비노출. 해당 시간봉마다 다시 계산. 24시간 거래대금 100만 USDT 이상인 알트만 사용.

비중 정책: 고정 총 노출 1배, 2배, 5배; 60일 후행 1배 비용 차감 수익의 0.25×μ/σ²(0~5배); 같은 계산에서 μ를 μ−표준오차로 바꾼 보수형. 비중은 현재 진입 시각까지 완료된 수익만 참조한다. 음수 추정 평균이면 현금.

## 체결·청산·비용 계약

완료된 봉만 보고 다음 봉 시가에 체결한다. 포지션을 수량으로 보유하며 재조정 거래대금에는 수수료를 부과한다. 기본 비용은 편도 거래대금의 0.09%, 스트레스는 0.18%(정확히 2배). 별도로 기본 1bp/일, 스트레스 3bp/일의 총 명목 노출당 보유비용 가정을 부과한다. 이는 실제 과거 펀딩 정산 자료가 아니다.

계좌 복리 시뮬레이션은 매 봉 보유 수량의 시가 평가부터 진행한다. 개별 코인의 불리한 고저가가 동시에 발생했다고 가정한 보수적 포트폴리오 하한과 다음 시가 갭을 사용한다. 하한 자산이 시작 명목 노출의 2% 이하이면 시장봉 청산 프록시로 처리하고 자산을 0으로 종료한다. 실제 Bitget mark price/MMR/margin mode 청산가와 같지 않다. 종료 후 회복을 수익에 합산하지 않는다. 구간 마지막에 전량 정리 비용을 부과한다.

## 선택·평가·실패 기억

모든 후보의 검증 일별 비용 차감 자산 경로를 저장한다. 검증에서 활동일 30일 이상, 스트레스 청산 프록시 0인 후보 중 스트레스 복리 수익률 최대 후보를 선택한다. 해당 후보가 손실이어도 연구상 순위와 실패 사실을 그대로 기록한다. 우승자, 각 신호군 검증 우승자, 우승 신호의 5개 비중 정책, 기존 1D Donchian 고정 2배를 **test 조회 전에** 평가 목록으로 고정하고 각 조합을 한 번씩 평가한다. test 결과에 따라 다시 선택하지 않는다.

195개 검증 경로의 8개 시간블록으로 수익 목적 CSCV-PBO를 계산한다. 비활동 후보 제외 여부와 동률 중간 순위 처리를 기록한다. 중첩 경로의 직렬 의존성 때문에 정밀 확률로 해석하지 않는다. 승자의 일별 test 수익에는 현행 DSR 근사 함수의 로컬 195회 및 누적 139,536+195회 보정을 각각 보고한다. 이 값만으로 독립 OOS나 실제 전역 DSR을 주장하지 않는다.

각 가설은 설정 해시, 출처, 부모 신호, 검증 결과, test 평가 여부, 실패 이유를 기록한다. 이는 실패 정보를 다음 실행에서 조회할 수 있게 만든 것이며 LLM 가중치 파인튜닝이나 수익 개선 증거가 아니다.

## 이번 범위 밖

옵션 Heston 전략에는 옵션 체인·호가·그릭·헤지 비용 자료가, 내부자 거래에는 당시 공개 시각이 붙은 지갑/공시 라벨이, 거래소 간 차익에는 동시 호가와 실제 체결 가능성이 필요하다. 해당 자료가 없는 시장 OHLC로 이 전략들을 검증했다고 표시하지 않는다. 자동 실거래 승격은 하지 않는다.

## 추가 사전등록 v2 — 사용자의 두 링크 추가, 수익 계산 전

첫 글의 옵션 대량 주문·GEX 주장은 당시 옵션 체결·bid/ask·그릭·딜러 포지션 추정 자료가 없어 직접 성과를 복제하지 못한다. 별도 **코인용 대체 가설**로 1시간 봉의 거래량 급증 후 종가 위치를 이용한 연속 움직임을 추가한다. 거래량은 현재 완료봉이 그 전 24봉 평균의 2/3배 이상이고, 종가가 해당 봉 고저 범위 상위 20%면 롱·하위 20%면 숏이다. 24시간 100만 USDT 유동성 조건과 ±1/13 비중, 6/24시간 유지(새 신호는 방향·시계 갱신)를 고정한다. 이것은 기관 주문, 실제 매수/매도 체결량 또는 GEX의 측정치가 아니다.

두 번째 글에서 시장봉만으로 정확하게 분리할 수 있는 규칙은 `volume.h6 / (volume.h24 / 4) < 0.20`의 청산 조건이다. 1시간 Donchian 및 위 4개 대체 신호에 0.20(원문)과 0.50(명시적 민감도)의 노출 중지·회복 시 재진입 필터를 붙이고 고정 1/2/5배만 비교한다. 6시간 거래량은 24시간 합에 포함되며 현재 미완료봉은 쓰지 않는다. 이 비교의 한 시간 관측은 원문의 5분 폴링/60초 체결 보장이 아니다. 일봉·4시간봉에서 6시간 값을 잘못 근사하지 않는다.

총 후보는 기존 195개 + 1H 대체 신호 4개×5개 비중=20개 + 1H 5개 신호×2개 거래량 필터×고정 비중 3개=30개, **245개**다. 전부 같은 검증 구간으로 선택하고 결과 확인 전 test 목록을 고정한다. 우승자의 5개 비중 정책은 동일 원천 신호·동일 필터 없음 조건으로 보고, 필터 효과는 1H Donchian 고정 2배의 off/0.20/0.50 세 조합을 사전 고정한 보조 비교로 함께 조회한다. 이 세 가지를 test를 보고 다시 선택하지 않는다.

원문 전체 밈코인 전략은 보유자 수 이력·수익자별 집중도·상장/소멸 토큰·실제 DEX 유동성·호가·체결 이력이 없어서 재현되지 않는다. 현재 생존 대형 알트의 OHLC로 87배 사례를 검증했다고 표현하지 않는다. 글에 제시된 수수료 최소액은 실제 거래소 요금 확인치가 아닌 수학 예시로만 사용한다. 예측시장은 당시 정보·교정된 독립 확률·호가가 없어 이번 PnL 실험에 포함하지 않는다.
