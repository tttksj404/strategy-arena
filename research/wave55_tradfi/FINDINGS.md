# Wave-55 — 새 자산군(전통자산 무기한)을 발견했다: **메커니즘은 성립, 캐리는 없음**

측정 2026-07-31 · **판정: 기각 (펀딩 중앙 0.00%)** — 그러나 자산군 자체는 실재하고 전진 수집 대상이다

---

## 0. 어디서 왔나

wave54까지 닫힌 축을 정리하니 두 가지가 미탐색으로 남았다:

1. **유휴자본 대여 수익률** — wave54가 차입을 연 60.13%로 실측했으니 대여도 높을 것이라 의심. wave18의 I5는 1.91%를 가정했고 캐리는 58%의 날만 활성이므로 유휴 42%의 수익률이 바뀌면 그림이 달라진다.
2. **`exchange_info`의 비(非)무기한 계약 134종** — 54개 wave에서 한 번도 열어보지 않았다.

## 1. 유휴자본 대여 — 상향 여지 없음

OKX `finance/savings/lending-rate-history` 실측: **USDT 대여 연 2.08~2.12%** (`rate` 상한 2.5%).

**wave18의 1.91% 가정이 사실상 정확했다.** 상향 여지가 없다.

부수 관찰: **차입 60.13% vs 대여 2.08% — 29배 스프레드**를 거래소가 가져간다. 이것이 wave54에서 레버리지가 닫힌 이유와 같은 구조다.

## 2. 🔍 발견 — 134종의 실체는 "전통자산 무기한"이었다

`binance_exchange_info.json`의 TRADING USDT 664종 분해:

| contractType | 수 |
|---|---|
| PERPETUAL | 530 |
| **TRADIFI_PERPETUAL** | **130** |
| CURRENT_QUARTER / NEXT_QUARTER | 4 |

**TRADIFI_PERPETUAL 130종의 기초자산**: 금(XAU)·은(XAG)·백금·팔라듐·구리·천연가스, 그리고 **미국 주식**(TSLA·NVDA·AAPL·MSFT·AMZN·GOOGL·META·SPY·QQQ·MSTR·COIN), 한국/일본 ETF(EWY·EWJ·KORU), OPENAI·ANTHROPIC까지.

**54개 wave에서 한 번도 본 적 없는 자산군이다.**

### 왜 중요해 보였나

wave52가 확정한 것: 암호자산 캐리 계열들은 종목이 하나도 겹치지 않아도(자카드 0.00) **수익률 상관 0.96** 이다. 공통 동인(암호자산 전반 펀딩 수준)이 갈라지지 않기 때문이다.

**금·주식의 캐리 동인은 USD 금리·배당·주식 대차이고 암호자산 심리와 무관하다.** 원리적으로 wave52가 찾지 못한 상관 분리가 여기 있다.

### 접근성 확인

Binance는 HTTP 451이고 캐시에 이 자산군 데이터가 **0종**이다(초기에 "25종 보유"로 보였던 것은 부분문자열 오탐 — `BTCUSDT`가 다른 파일명에 포함되는 식이었다).

그런데 **접근 가능한 거래소에 있다**:
- **Bitget**: XAUUSDT·XAGUSDT·XPTUSDT·COPPERUSDT·NATGASUSDT·SPYUSDT·QQQUSDT·TSLAUSDT·NVDAUSDT·AAPLUSDT·MSFTUSDT·AMZNUSDT·METAUSDT·COINUSDT·MSTRUSDT
- **OKX SWAP**: 동일 계열 + **만기 금선물** `XAU-USD_UM-260807/260828/260925/261225/270326`

## 3. 델타중립 구성은 성립한다 (실측)

금 캐리를 위해서는 현물 다리가 필요하다. **XAUT-USDT(Tether Gold)·PAXG-USDT 가 OKX·Bitget 양쪽에 있다.**

**XAUT-USDT 현물 vs XAU-USDT-SWAP 무기한, 300일 겹침 (2025-10-04 ~ 2026-07-30):**

| | 값 |
|---|---|
| **일간수익 상관** | **0.9981** |
| 베이시스(퍼프/현물−1) 중앙 | +0.159% |
| 베이시스 범위 | −0.104% ~ +0.618% |
| **잔차 일간 표준편차** | **0.089%** |
| **잔차 연환산 변동성** | **1.7%** |

PAXG는 상관 0.9963, 잔차 연변동성 2.3%.

**메커니즘이 성립한다.** 상관 0.9981은 델타중립이 실제로 중립이라는 뜻이고, 잔차 위험이 연 1.7%로 작다.

유동성: XAUT 현물 **$16.5M/일**(충분), XAU 무기한 $65k/일(얇지만 $45 주문에는 무관). **만기 금선물은 거래대금 0** — 실행 불가.

## 4. 🚨 그런데 캐리가 없다 — +44.21%는 단일 시점 이상치였다

첫 관측에서 XAU 무기한 펀딩이 **+44.21% APR**이었다. $45 노셔널이면 연 $19.90 — wave42 전체 전략의 기대치($2~4)를 압도한다.

**펀딩 이력을 페이징으로 소급해 실측하니 무너졌다.**

**XAU-USDT-SWAP, 276스탬프 / 92일 (2026-04-30 ~ 2026-07-31):**

| | 금(XAU) | BTC (대조) |
|---|---|---|
| **APR 중앙** | **+0.00%** | **+3.24%** |
| APR 평균 | +5.31% | +3.10% |
| p90 | +21.93% | +9.49% |
| **양수 스탬프 비율** | **31.2%** | **75.4%** |
| 15% APR 초과 비율 | 16.3% | 0.0% |
| 월별 중앙 APR | −3% · +0% · +0% · +0% | −7% · +3% · +1% · +5% |

**금 펀딩은 중앙값이 정확히 0이고 31%의 스탬프에서만 양수다.** 평균 5.31%는 간헐적 스파이크(p90 21.93%)가 만든 것이다.

**대조가 결정적이다: BTC는 중앙 +3.24%에 양수 비율 75.4%로 훨씬 일관된다.** 금의 최고치가 높을 뿐 캐리로서는 열등하다.

즉 **+44.21%는 16.3%의 확률로 발생하는 스파이크를 하필 관측한 것**이다. wave52의 `majors`(t=−0.21), wave53의 `usdtVolume` 오측, wave54의 예측검정과 같은 계열의 함정을 또 만났고, 이번에도 **한 시점을 믿지 않고 이력을 소급한 것이 잡아냈다.**

## 6. 결론

- **유휴자본 대여 축 닫힘**: 실측 2.08%, wave18 가정(1.91%)과 사실상 동일.
- **전통자산 무기한 축: 자산군은 실재하고 메커니즘도 성립하나(상관 0.9981, 잔차 1.7%) 캐리가 없다**(펀딩 중앙 0.00%, 양수 31.2%).
- **금 무기한은 BTC보다 캐리로서 열등하다** — 중앙 0.00% vs +3.24%, 양수 31.2% vs 75.4%.
- **만기 금선물은 거래대금 0으로 실행 불가.**
- **이력 92~300일로 백테스트 불가.** 지금 판정은 잠정적이며, 92일은 하나의 레짐이다.
