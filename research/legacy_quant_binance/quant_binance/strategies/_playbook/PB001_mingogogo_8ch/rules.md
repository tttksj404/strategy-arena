## 2. CH1 (단타용 미니맵 v5.1) — 10지표 가중치 (정확)

| # | 지표 | 계산 | 매수 임계 | 매도 임계 | **가중치** | pandas-ta 매핑 |

| 1 | RSI | 14봉 RSI | ≤ 30 | ≥ 70 | **15%** | `ta.rsi(close, length=14)` |

| 3 | MFI | 14봉 MFI | ≤ 20 | ≥ 80 | **12%** | `ta.mfi(high, low, close, volume, length=14)` |
| 4 | CCI | 20봉 CCI | ≤ -100 | ≥ +100 | **10%** | `ta.cci(high, low, close, length=20)` |
| 5 | Williams %R | 14봉 W%R | ≤ -80 | ≥ -20 | **10%** | `ta.willr(high, low, close, length=14)` |
| 6 | BB%B | %B = (price-Lower)/(Upper-Lower) | ≤ 0.2 | ≥ 0.8 | **10%** | `ta.bbands(close, 20, 2.0)['BBP_20_2.0']` |
| 7 | MACD Histogram | 12/26/9, 음→양 전환 매수 | hist↑ 전환 | hist↓ 전환 | **8%** | `ta.macd(close, 12, 26, 9)['MACDh_12_26_9']` |

## 5. CH3 (Z-Score 퀀트 — 차트 분석기 독점)

```
Alpha Score = f(Z_MR, Z_OF, Z_VOL) ∈ [-1, +1]

  Z_MR  = VWAP 대비 가격 편차 (mean reversion)
  Z_OF  = 거래량 비율 (order flow)
  Z_VOL = ATR 기반 변동성
```

| Alpha Score | 신호 |
|---|---|
| ≥ +0.85 | 극강 매수 |
| +0.5 ~ +0.85 | 강한 매수 |
| +0.2 ~ +0.5 | 약한 매수 |
| -0.2 ~ +0.2 | 중립 |
| -0.5 ~ -0.2 | 약한 매도 |
| -0.85 ~ -0.5 | 강한 매도 |
| ≤ -0.85 | 극강 매도 |

**특성**: 추세 추종 (가격 상승 시 양수). 추세가 진행 중일 때 신뢰도 높음. → mean-reversion 으로 보이는 이름과 달리 실제 동작은 trend-following 가까움.

post 308 사례: ANKR=100, KITE=90 ← 이는 0-100 으로 별도 정규화된 표기 (\[+0.85 → 100, +0.5 → 70~80\] 추정).

**구현 노트**: Bitget/Binance 포팅 시 VWAP 은 funding-window 단위 (8h) 로 계산하거나, daily-VWAP rolling 으로 근사.

## 6. CH7 (Squeeze Momentum)

- BBands(20, 2.0) ∩ Keltner(20, 1.5) 비교
- Squeeze ON: BB 폭 ≤ Keltner 폭 (변동성 수축)
- Squeeze OFF: BB 폭 > Keltner 폭 (확장)
- 최적 진입: **Squeeze OFF 직후 + 모멘텀 히스토그램 양수 증가** (post 262 line 428)
- pandas-ta: `ta.squeeze(high, low, close, bb_length=20, kc_length=20, mom_length=12)`

## 7. CH8 (급락 경고 — Risk Filter)

> post 293 의 SAND 사례에서 정량화. **메인 시그널이 아니라 진입 거부 게이트** (kill switch 성격).

```
경고 점수 = f(BTC return, ALT median return, 매수세 소실 정도) ∈ [0, 100]
```

| 점수 | 등급 | 의미 |
|---:|---|---|
| 95~100 | **CRITICAL** | 15분 내 수직 낙하 임박 → 진입 금지 + 보유 청산 |
| 80~94 | **HIGH** | 지지선 붕괴 임박 → 신규 진입 차단 |
| 50~79 | MODERATE | 점진적 하락 우세 → 사이즈 축소 |
| < 50 | NONE | 정상 |

**구현 권장**: BTC 1h 수익률 + 코인 universe 의 alt-median 1h 수익률 → 둘 다 음수 + alt-median 이 -X% 이하 → HIGH. 정확한 가중치는 미공개.

## 8. 진입 / 청산 룰 (post 262 line 139-151, 461-465)

### 진입 (단타용 미니맵 기본 전략)

조건 모두 충족 시 매수:
1. CH1 종합 점수 **≥ 70**
2. CH1 신호 **LONG**
3. CH2 MTF 컨센서스 **STRONG LONG** (3개 이상 TF 일치)
4. BB%B ≤ 0.2 (볼린저 하단 근접)
5. RSI ≤ 30 AND Stochastic ≤ 20 (과매도 동시)

### 진입 (차트 분석기 강화 전략, 위 + 아래 3개 이상 충족)

1. RSI 30-40 구간에서 **상승 전환** (반등 확인)
2. Squeeze OFF + 양수 모멘텀 증가
3. Z-Score Alpha ≥ +0.5
4. RCI 단기선(9일) -80 이하에서 상승 전환

### 청산 (3단 분할)

| 단계 | 익절가 (단타) | 익절가 (스윙) |
|---|---|---|
| TP1 | +5% | BB 중간선 (Middle) |
| TP2 | +10% | BB 상단선 (Upper) |
| TP3 | +15% | RSI ≥ 70 OR RCI ≥ +80 시 전량 |

**손절**: 진입가 대비 **-3% ~ -5%** OR BB 하단 이탈 (둘 중 빠른 쪽).

### Risk Gate (CH8)

- 비트코인 급락 중 → 알트 매수 자제 (post 262 line 148)
- 30개 코인 중 80% 이상 SHORT → 시장 전체 하락, 관망
- CH8 점수 ≥ 80 → 신규 진입 전면 차단
- 단타이므로 **1시간 이상 보유 권장하지 않음** (post 262 line 151)
