# 경험 기록: Strategy Arena — 암호화폐 퀀트 연구와 검증 가드레일

- 계열: `strategy-arena`(대표), `bitget-5x-research`(빈 레포, 내용은 이 레포 `research/bitget_5x`로 통합). RaceLens(경륜·경마) 코드는 2026-07-15에 다른 레포로 분리됨
- 기간: 2026-06 ~ 2026-11 (커밋 이력 기준, 89건. 암호화폐 연구 통합 문서 2026-08-24)
- 인원·구성: 커밋 저자 이름 3종(동일인 여부 미확인), 협업자 기록 없음(Claude·Codex 발화 검색, 2026-11-24: 동일인 여부 발화 없음)
- 본인 역할: 전략 구성·백테스트 엔진, 연구 가드레일 문서, 공개 시장데이터 기반 5x 리플레이 코어 정리 (코딩은 AI 모델에 시키도록 사용자가 지시, 세부 분담은 미확인. 사용자 작업 지시, 2026-07)
- 성격: 개인 프로젝트·포트폴리오(실거래 시스템 아님). 실사용자 없음
- 최종 갱신: 2026-11-23

## 1. 상황과 판돈
- 무엇 때문에 시작했나: 전략 아이디어를 입력해 시뮬레이션·지표·위험 해석까지 보이는 백테스트 도구와, 흩어진 암호화폐 연구를 한곳에 정리하려는 목적(README). 사용자는 코인 퀀트 알고리즘을 "계속 찾았는데 없어서" 소액 자본으로 안정적으로 수익을 극대화할 알고리즘을 찾아 달라고 했고, 거래소는 Bitget 선물(주식 ETF 포함)까지 고려하라고 했다(사용자 작업 지시, 2026-07).
- 왜 중요했나: 금융 데이터 분석에서 백테스트 결과를 실거래 주장과 분리해 검증하는 방법을 보이는 것이 목표
- 그때의 제약: 공개 시장데이터만 사용, 주문·레버리지·계정 접근 코드 제외, 비밀키 비포함

## 3. 판단
- 정한 것: 모든 실험에 데이터 출처, 샘플링 간격, 피처 가용 시점, 학습·검증·테스트 경계, 수수료·슬리피지, 재현 설정을 기록. 시간 순서를 지키는 검증만 인정(docs/RESEARCH_GUARDRAILS.md)
- 정한 사람: 본인(작성 주체 미확인). 사용자는 "과최적화 검증 제대로 일단 해놓고 paper 돌려놔"라고 지시해 과최적화 검증을 선행 조건으로 정했다(사용자 작업 지시, 2026-07). 거래소 기준도 "bitget으로 봐야하는데 binance가 아니라?"라며 Bitget으로 바로잡았다(사용자 작업 지시, 2026-07).
- 버린 선택지: 실거래 실행 경로와 자격증명 경로는 공개 레포에서 의도적으로 제외
- 판단 근거: 수익률 주장과 연구 결과를 분리하기 위해
