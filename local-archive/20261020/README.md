# Local backup 2026-10-20

Every working copy is listed in INDEX.json. Source previews are in source/, complete source and data files are in the linked GitHub Releases. Download all ZIP parts for a root and extract them into one directory. Each manifest lists every archived file's SHA-256. Git history bundles can be cloned using git clone history.bundle. A root's OriginalHead identifies its original revision. Sensitive files and flagged history are encrypted with AES-256-GCM (KSAR0001); the project key is retained only in the owner's local StorageCleanupRetained/KraStrategyKeys-20261020 folder. Use Restore-ProjectArchive.ps1 with the key file to restore encrypted assets. Cache and environment roots are intentionally excluded. Existing main source files have been preserved.
