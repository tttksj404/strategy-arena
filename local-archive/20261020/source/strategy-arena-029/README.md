# Strategy Arena

Strategy Arena is a public workspace for crypto-quant research: reproducible market-data analysis, strategy experiments, realistic backtesting, and portfolio-risk evaluation.

## Direction

- Build research datasets with clear provenance and time boundaries.
- Test hypotheses with fees, slippage, liquidity assumptions, and out-of-sample splits.
- Compare strategies by risk-adjusted behavior, drawdown, and capacity, not headline return alone.
- Publish experiment notes that make failures as inspectable as successful results.

## Safety boundary

This repository is for research and simulation only. It contains no exchange credentials, no automated order execution, and no investment advice. Any future integration must remain opt-in, credential-free by default, and independently reviewed.

See `docs/RESEARCH_GUARDRAILS.md` for the operating standard.
